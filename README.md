# intent-check

The `intent` plugin for Claude Code and Codex. It checks code your agent writes against what you actually asked for, quietly, and reports concerns with a link to a shareable report.

Status: private pre-release, under construction. Install instructions will land here before dogfooding.

- Contract with the backend: `contract/` (identical copy in `nlp-research-rosu/intent-check-prover`).
- Zero runtime dependencies. Node 18 or newer.
